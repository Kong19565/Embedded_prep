🔴 PART 1: ข้อสอบเก็งตอนเช้า (ปิดตำรา - 10 ข้อ)
ข้อที่ 1: กำหนดให้ F = A'B'C + A'BC + AB'C จงลดรูปสมการด้วยพีชคณิตบูลีนให้เหลือรูปอย่างง่ายที่สุด
ก. F = A + B
ข. F = C (A' + B') หรือ F = C · (A · B)'
ค. F = A' · B
💡 เฉลยวิธีคิดทีละขั้นตอน:
1. ดึงตัวร่วม C ออกจากสมการ: F = C · (A'B' + A'B + AB')
2. ดึง A' ออกจากสองเทอมแรก: A'B' + A'B = A'(B' + B) = A'(1) = A'
3. จะได้ F = C · (A' + AB') = C · (A' + A)(A' + B') = C · (1)(A' + B') = C · (A' + B')
ข้อที่ 2: วงจรบวก Full Adder มีอินพุต A=1, B=1, Cin=1 ผลลัพธ์ Sum และ Carry Out จะเป็นเท่าใด?
ก. Sum = 1, Carry Out = 1
ข. Sum = 0, Carry Out = 1
ค. Sum = 1, Carry Out = 0
💡 เฉลยวิธีคิดทีละขั้นตอน:
• Sum = A ⊕ B ⊕ Cin = 1 ⊕ 1 ⊕ 1 = 0 ⊕ 1 = 1
• Cout = AB + Cin(A ⊕ B) = (1·1) + 1(1 ⊕ 1) = 1 + 1(0) = 1
ดังนั้น Sum = 1 และ Carry Out = 1 (ผลบวก 1+1+1 = 3 หรือ 11b)
ข้อที่ 3: ข้อใดอธิบายเหตุผลหลักที่ใช้ Harvard Architecture ใน AVR Microcontroller ได้ถูกต้องที่สุด?
ก. แยกบัส Flash ROM และ Data SRAM ทำให้ดึงคำสั่งและอ่านข้อมูลได้พร้อมกันใน 1 คาบ Clock
ข. เพื่อประหยัดหน่วยความจำ RAM ในชิป
💡 เฉลยวิธีคิด: สถาปัตยกรรม Harvard แยกโปรแกรมและข้อมูลออกเป็นคนละบัส ทำให้กระบวนการ Fetch และ Execute ทำงานคาบเกี่ยวกันได้ เพิ่มความเร็วเป็น 1 คำสั่งต่อ 1 คาบนาฬิกา
🟢 PART 2: ข้อสอบเก็งตอนบ่าย (เปิดตำรา - 10 ข้อ)
ข้อที่ 11: คำสั่ง AVR Assembly ในข้อใดใช้สำหรับตั้งค่าบิตพอร์ตให้เป็นเอาต์พุต 1 บิต โดยไม่กระทบบิตอื่น?
ก. SBI PORTB, 5
ข. OUT PORTB, R16
ค. LDI PORTB, 5
💡 เฉลยวิธีคิด: SBI (Set Bit in I/O) ใช้ตั้งค่าบิตเฉพาะตำแหน่งใน I/O Register ให้เป็น 1 โดยไม่ต้องดึงมารวมบิตด้วย OR
ข้อที่ 12: หากต้องการวนลูป 100 รอบในภาษา AVR Assembly ควรใช้คำสั่งใดในการลดค่าตัวนับและตรวจสอบจบลูป?
ก. DEC R16 ร่วมกับ BRNE label
ข. INC R16 ร่วมกับ BREQ label
💡 เฉลยวิธีคิด: คำสั่ง DEC R16 จะลดค่าลง 1 หากค่ายังไม่เป็น 0 ธง Z จะเป็น 0 ทำให้คำสั่ง BRNE (Branch if Not Equal) กระโดดกลับไปทำในลูปต่อ

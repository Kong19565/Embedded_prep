สรุปเจาะลึกจากตำราเรียนสากล (Enoch Hwang, M. Morris Mano, Mazidi AVR) สำหรับการเตรียมสอบวิชา Embedded System Design

คำสั่งคณิตศาสตร์และลอจิก

1. ชุดคำสั่งคำนวณ ALU ใน AVR

• ADD / ADC: บวกค่าแบบไม่รวมตัวทด / รวมตัวทด Carry
• SUB / SUBI / SBC: ลบค่าจากรีจิสเตอร์ / ลบค่าคงที่ K / ลบรวมตัวทด Carry
• MUL: คำสั่งคูณเลข 8 บิตแบบไม่มีเครื่องหมาย MUL Rd, Rr ผลลัพธ์ 16 บิตจะถูกบันทึกในคู่รีจิสเตอร์ R1:R0

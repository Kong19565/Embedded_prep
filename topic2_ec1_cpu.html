1. สถาปัตยกรรม Von Neumann & โครงสร้าง Datapath ของ EC-1

Microprocessor EC-1 เป็นระบบประมวลผลขนาด 8 Bit ที่มีโครงสร้าง Datapath และหน่วยควบคุมเชื่อมต่อกันอย่างเป็นระบบ:

Accumulator💡 Accumulator: รีจิสเตอร์สะสม (ACC): รีจิสเตอร์หลักใน CPU สำหรับเก็บผลลัพธ์การคำนวณจาก ALU ชั่วคราว ALU💡 ALU: Arithmetic Logic Unit (หน่วยคำนวณและลอจิก): หัวใจของ CPU ทำหน้าที่บวก ลบ และเปรียบเทียบลอจิก AND/OR/XOR

2. วงรอบการประมวลผล 3 ขั้นตอน (3-Stage Instruction Cycle)

1️⃣ Stage 0: S0 (Fetch)

ดึงคำสั่งจากหน่วยความจำ ROM ณ ที่อยู่ Program Counter (PC) มาเก็บไว้ใน Instruction Register (IR)

IR ← Memory[PC]
PC ← PC + 1

2️⃣ Stage 1: S1 (Decode)

ถอดรหัส Opcode💡 Opcode: Operation Code (รหัสคำสั่ง): รหัสฐานสองส่วนแรกของชุดคำสั่งที่ระบุให้ CPU รู้ว่าต้องทำคำสั่งอะไร เช่น ADD, SUB จาก Bit 7..4 ของ IR เพื่อส่งสัญญาณให้ Control Unit เตรียมเส้นทางข้อมูล

Opcode💡 Opcode: Operation Code (รหัสคำสั่ง): รหัสฐานสองส่วนแรกของชุดคำสั่งที่ระบุให้ CPU รู้ว่าต้องทำคำสั่งอะไร เช่น ADD, SUB ← IR[7..4]
Operand ← IR[3..0]

3️⃣ Stage 2: S2 (Execute)

ALU ดำเนินการประมวลผลคำนวณ บวกลบ หรือย้ายข้อมูล แล้วบันทึกผลลัพธ์ลง Accumulator💡 Accumulator: รีจิสเตอร์สะสม (ACC): รีจิสเตอร์หลักใน CPU สำหรับเก็บผลลัพธ์การคำนวณจาก ALU ชั่วคราว

ACC ← ALU_Out
(หรือ Memory[addr] ← ACC)

3. ตารางชุดคำสั่งของ EC-1 Microprocessor (Instruction Set Spec)

Opcode (Hex) Mnemonic รูปแบบ Operand การทำงานทางคณิตศาสตร์/ตรรกะ ผลกระทบต่อ Register
0x1 LDA addr Memory Address (4-bit) อ่านข้อมูลจาก Memory[addr] โหลดเข้า Accumulator ACC ← Memory[addr]
0x2 ADD addr Memory Address (4-bit) นำค่าใน Accumulator บวกกับข้อมูลใน Memory[addr] ACC ← ACC + Memory[addr]
0x3 SUB addr Memory Address (4-bit) นำค่าใน Accumulator ลบด้วยข้อมูลใน Memory[addr] ACC ← ACC - Memory[addr]
0x4 STA addr Memory Address (4-bit) เขียนบันทึกข้อมูลจาก Accumulator ลงใน Memory[addr] Memory[addr] ← ACC
0x5 JMP addr Target Address (4-bit) กระโดดข้ามไปยังที่อยู่คำสั่งปลายทางโดยไม่มีเงื่อนไข PC ← addr
0x6 JNZ addr Target Address (4-bit) กระโดดไปยังที่อยู่ปลายทาง เฉพาะเมื่อ Accumulator ≠ 0 If ACC ≠ 0 Then PC ← addr

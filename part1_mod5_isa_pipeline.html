🔴 Module 5: Instruction Set Architecture (ISA) & 5-Stage Pipeline CPU (Enoch Hwang Ch 8 / Micro5)

สรุปเจาะลึกจากตำราเรียนสากล (Enoch Hwang, M. Morris Mano, Mazidi AVR) สำหรับการเตรียมสอบวิชา Embedded System Design

สถาปัตยกรรมไปป์ไลน์

1. สถาปัตยกรรม CPU 5-Stage Pipeline & Hazards

📌 5 สเตจของไปป์ไลน์ (What):
1. IF (Instruction Fetch): ดึงคำสั่งจาก Flash ROM ตาม Program Counter
2. ID (Instruction Decode): ถอดรหัสคำสั่งและอ่านค่าจาก Register File
3. EX (Execute): ประมวลผลทางคณิตศาสตร์/ลอจิกด้วย ALU
4. MEM (Memory Access): อ่าน/เขียนข้อมูลใน SRAM (คำสั่ง Load/Store)
5. WB (Write Back): บันทึกผลลัพธ์ย้อนกลับลง Register File
❓ ข้อผิดพลาดวิกฤต (Pipeline Hazards):
• Structural Hazard: ฮาร์ดแวร์ไม่พอ (แก้โดยแยก Memory Instruction/Data)
• Data Hazard (RAW): คำสั่งถัดไปต้องการใช้ผลลัพธ์ที่คำสั่งก่อนหน้ายังเขียนไม่เสร็จ (แก้โดยทำ Data Forwarding/Bypassing หรือแทรก Stall/NOP)
• Control Hazard: คำสั่ง Branch/Jump เปลี่ยนทิศทางกระโดด (แก้โดยทำ Branch Prediction หรือ Flush สเตจ)

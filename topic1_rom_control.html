1. เปรียบเทียบหน่วยควบคุมแบบ Hardwired vs Microprogrammed

⚡ Hardwired Control Unit

สร้างจาก Combinational Logic Gates และ D Flip-Flops เพื่อสร้างสัญญาณควบคุมออกมาโดยตรง:

- ข้อดี: ความเร็วสูงสุดในการประมวลผล ประหยัดพื้นที่ชิปฮาร์ดแวร์
- ข้อเสีย: ไม่มีตารางข้อมูล ต้องออกแบบ Boolean Equations ใหม่ทั้งหมดหากเพิ่มหรือดัดแปลงชุดคำสั่ง

💾 Microprogrammed Control Unit

เปลี่ยนสัญญาณควบคุมให้อยู่ในรูปข้อมูลรหัส (Microinstruction) เก็บบันทึกไว้ใน ROM (Control Store):

- ข้อดี: ยืดหยุ่นสูงมาก การแก้ไขหรือเพิ่มคำสั่งทำได้ง่ายเพียงแก้ไขค่า Hex ใน ROM โดยไม่ต้องแตะสายไฟแม้แต่เส้นเดียว
- ข้อเสีย: ช้ากว่าเล็กน้อยเนื่องจากต้องใช้รอบเวลาอ่านหน่วยความจำ (Memory Access Time)

3. โครงสร้าง Microinstruction และสมการ Branch Logic

📐 รูปแบบ Microinstruction (8 Bit Specification)

Bit 7: CLR_CNT (1 = ล้างค่า Counter เป็น 0)
Bit 6: INC_CNT (1 = เพิ่มค่า Counter ขึ้น +1)
Bit 5: EN_DISP (1 = เปิด Tri-State แสดงผลออก Hex Display)
Bit 4: JMP_EN (1 = เปิดการกระโดดไปยังที่อยู่ปลาทาง)
Bits 3..0: ADDR (ที่อยู่ ROM ปลายทางที่ต้องการกระโดดไป)

⚡ สมการวงจรตัดสินใจกระโดด (Branch Logic)

สัญญาณเลือก MUX💡 MUX: Multiplexer (วงจรเลือกข้อมูล): วงจรดิจิทัลที่เลือกนำข้อมูลจากหลายอินพุตออกสู่เอาต์พุตเดียวตามสัญญาณ Select Lines (SEL) คำนวณจากสมการ Boolean เชิงผสม:

SEL = JMP_EN · (EQ + NOT COMP_EN)

• หาก SEL = 0 : เลือกที่อยู่ถัดไป (μPC + 1)
• หาก SEL = 1 : เลือกที่อยู่กระโดด (ADDR3..0)

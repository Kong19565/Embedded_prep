1. โครงสร้าง I/O Bus และ Interface Unit

🖥️ บทบาทของ I/O Interface Unit

อินเทอร์เฟซทำหน้าที่แปลงสัญญาณและเชื่อมต่ออุปกรณ์ต่อพ่วง (Peripherals) เข้ากับ CPU Bus:

• Data Conversion: แปลงข้อมูลระหว่าง Parallel Bus กับ Serial Data
• Synchronization: ปรับความเร็วที่แตกต่างกันมากระหว่าง CPU (ระดับ GHz) กับ I/O Device (ระดับ KHz)
• Address Decoding: ตรวจจับรหัสที่อยู่พอร์ต (I/O Port Address)

🗺️ Isolated I/O vs Memory-Mapped I/O

  • Isolated I/O: แยกชุดคำสั่งอ่านเขียนพอร์ตเฉพาะ (เช่น `IN`, `OUT`) แยกสาย Read/Write บัสกับ Memory
  • Memory-Mapped I/O: มองพอร์ต I/O เป็นที่อยู่หนึ่งใน Memory Space ใช้คำสั่งเดียวกับ Memory (เช่น `LDS`, `STS`)

2. การส่งสัญญาณข้อมูลแบบไม่อิงนาฬิกา (Asynchronous Data Transfer)

⚡ Strobe Control Scheme

ใช้สายสัญญาณ Strobe เพียงเส้นเดียวในการแจ้งเตือนการส่งข้อมูล:

Source-Initiated: [ส่ง Data] → [จุด Strobe High] → [Destination อ่านค่า]
• ข้อเสีย: ไม่มีสัญญาณยืนยันกลับว่าผู้รับได้รับข้อมูลเรียบร้อยแล้วหรือไม่

🤝 Handshaking Protocol (2-Way Confirmation)

ใช้สายสัญญาณควบคุม 2 เส้น (Data Valid และ Data Accepted):

1. Source ส่ง Data และขึ้นสัญญาณ Data Valid
2. Destination อ่าน Data แล้วขึ้นสัญญาณ Data Accepted ยืนยัน
3. Source ลงสัญญาณ Data Valid → Destination ลงสัญญาณ Data Accepted
• ข้อดี: ปลอดภัยสูงสุด ป้องกันการสูญหายของข้อมูลบนสาย Bus

3. โหมดการรับส่งข้อมูล (Modes of Transfer) & Priority Interrupts

โหมดการส่งข้อมูล กลไกการทำงาน ข้อดี / ข้อเสีย
Programmed I/O (Polling) CPU วนลูปอ่าน Flag สถาวะของอุปกรณ์ I/O ตลอดเวลาจนกว่าจะพร้อมส่งข้อมูล ❌ เสียเวลา CPU ทรัพยากรค้างวนลูปไร้ประโยชน์ (CPU Waste)
Interrupt-Initiated I/O อุปกรณ์ I/O ส่งสัญญาณขัดจังหวะ (Interrupt Request: IRQ) เมื่อพร้อม CPU จึงสลับไปทำงาน Interrupt Service Routine (ISR) ✅ CPU ทำงานอื่นได้เต็มที่ แต่ยังเสียเวลาสลับ Context สแต็ก Register
Direct Memory Access (DMA) ย้ายการส่งข้อมูลก้อนใหญ่ (Block Transfer) ให้ DMA Controller จัดการส่งเข้า Memory โดยตรงโดยไม่ผ่าน CPU ⚡ ประสิทธิภาพสูงสุด ความเร็วในการย้ายข้อมูลสูงที่สุดในระบบคอมพิวเตอร์

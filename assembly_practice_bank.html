🟢 PART 2: แม่แบบโค้ดเก็งข้อสอบเขียนโปรแกรมภาษา AVR Assembly (10 โจทย์ยอดฮิต)

💻 ชุดฝึกเขียนโค้ด AVR Assembly 10 โจทย์เก็งข้อสอบตอนบ่าย พร้อมคำอธิบายโค้ดทีละบรรทัด

รวบรวมพิมพ์เขียวโครงสร้างโค้ดภาษาแอสเซมบลีสำหรับนำเข้าห้องสอบและดัดแปลงตอบโจทย์ข้อสอบเขียนโปรแกรมบ่ายวันนี้!

โจทย์ที่ 1: การนับเลขคู่ 0-20 ออกพอร์ต PORTB

1. โปรแกรมส่งค่าเลขคู่ 0, 2, 4, ..., 20 ออก PORTB

.INCLUDE "M328PDEF.INC"
.ORG 0x0000

LDI R16, HIGH(RAMEND)   ; 1. ตั้งค่า Stack Pointer
OUT SPH, R16
LDI R16, LOW(RAMEND)
OUT SPL, R16

LDI R16, 0xFF           ; 2. กำหนดให้ PORTB เป็นเอาต์พุตทั้งหมด
OUT DDRB, R16

CLR R17                 ; 3. ให้ R17 = 0 (ตัวนับเริ่มต้นเลขคู่)

COUNT_EVEN_LOOP:
    OUT PORTB, R17      ; ส่งค่าเลขคู่ออก PORTB
    CPI R17, 20         ; เปรียบเทียบกับ 20
    BREQ LOOP_RESET     ; ถ้าเท่ากับ 20 ให้กระโดดไปรีเซ็ต
    SUBI R17, -2        ; R17 = R17 + 2 (บวกเพิ่มทีละ 2)
    RJMP COUNT_EVEN_LOOP

LOOP_RESET:
    CLR R17             ; วนกลับไปเริ่มที่ 0 ใหม่
    RJMP COUNT_EVEN_LOOP
โจทย์ที่ 2: การอ่านปุ่มกดพอร์ต C ควบคุมไฟ LED พอร์ต B

2. อ่านสวิตช์ PINC บิต 0 (Active Low) กดแล้วไฟ PB5 สว่าง

.INCLUDE "M328PDEF.INC"
.ORG 0x0000

SBI DDRB, 5             ; ตั้งขา PB5 เป็นเอาต์พุต (LED)
CBI DDRC, 0             ; ตั้งขา PC0 เป็นอินพุต (Switch)
SBI PORTC, 0            ; เปิด Pull-up Resistor บน PC0

MAIN:
    SBIC PINC, 0        ; ข้ามคำสั่งถัดไปถ้าสวิตช์ PC0 ถูกกด (เป็น 0)
    RJMP LED_OFF        ; ถ้าไม่ได้กด (เป็น 1) กระโดดไปปิดไฟ
LED_ON:
    SBI PORTB, 5        ; ติดไฟ LED บน PB5
    RJMP MAIN
LED_OFF:
    CBI PORTB, 5        ; ดับไฟ LED บน PB5
    RJMP MAIN

1. สถาปัตยกรรม AVR RISC 8-bit & Status Register (SREG)

🏗️ Harvard Architecture & Register File

  • Harvard Architecture: แยกหน่วยความจำ Flash Program (32 KB) และ SRAM Data (2 KB) ออกจากกัน
  • Register File (R0..R31): มี Register ขนาด 8 Bit จำนวน 32 ตัว โดยมีคู่พิเศษใช้เป็น 16-bit Pointers:
    • X = R27:R26
    • Y = R29:R28
    • Z = R31:R30

🚩 Status Register (SREG Flags)

Bit 7: I (Global Interrupt Enable)
Bit 6: T (Bit Copy Storage)
Bit 5: H (Half Carry Flag)
Bit 4: S (Sign Bit = N ⊕ V)
Bit 3: V (Overflow Flag)
Bit 2: N (Negative Flag)
Bit 1: Z (Zero Flag)
Bit 0: C (Carry Flag)

2. การจัดการพอร์ต I/O ในภาษา C และ Assembly

การทำงานกับพอร์ต I/O โค้ดภาษา C (Bitwise Manipulations) โค้ดภาษา AVR Assembly คำอธิบายกระบวนการในฮาร์ดแวร์
ตั้งขา PB5 เป็น Output DDRB |= (1 << PB5); SBI DDRB, 5 เขียนค่า 1 ลงในบิต 5 ของ Data Direction Register
สั่งเปิดไฟ (HIGH) PORTB |= (1 << PB5); SBI PORTB, 5 ส่งแรงดันไฟฟ้า 5V ออกขาทรงพลังงานเปิดไฟ LED
สั่งปิดไฟ (LOW) PORTB &= ~(1 << PB5); CBI PORTB, 5 ส่งแรงดันไฟฟ้า 0V ตัดกระแสไฟ LED
สลับสถานะไฟ (Toggle) PORTB ^= (1 << PB5); IN R16, PORTB
LDI R17, (1<<5)
EOR R16, R17
OUT PORTB, R16		 ทำการ Exclusive-OR สลับบิตจาก 0 เป็น 1 หรือ 1 เป็น 0

3. สรุปชุดคำสั่ง AVR Assembly ที่ออกสอบบ่อย

📦 Data Transfer

  • LDI R16, K: โหลดค่าคงที่ K เข้า R16
  • MOV Rd, Rr: ก๊อปปี้ค่าจาก Rr ไป Rd
  • IN Rd, P: อ่านค่าจาก I/O Port P
  • OUT P, Rr: ส่งค่าออก I/O Port P

➕ Arithmetic & Logic

  • ADD Rd, Rr: นำ Rd + Rr
  • SUB Rd, Rr: นำ Rd - Rr
  • CPI Rd, K: เปรียบเทียบ Rd กับค่า K
  • INC / DEC Rd: เพิ่ม/ลดค่าขึ้นลง 1

🔀 Branching & Control

  • RJMP Label: กระโดดไปยัง Label
  • BREQ Label: กระโดดหากเท่ากัน (Z=1)
  • BRNE Label: กระโดดหากไม่เท่ากัน (Z=0)
  • SBI / CBI: ตั้งค่า/ล้างค่าบิต I/O

4. Interactive AVR Assembly Line-by-Line Stepper

จำลองการรัน AVR Assembly โค้ดไฟกระพริบ

ดูการทำงานของ R16, R17, DDRB, PORTB และสถานะ LED จริง

 1:  LDI  R16, 0b00100000  ; เตรียม Mask บิต 5
 2:  OUT  DDRB, R16        ; ตั้ง PB5 เป็น Output
 3:  LDI  R17, 0b00100000  ; เตรียมค่า HIGH
 4:  OUT  PORTB, R17       ; สั่งเปิดไฟ LED
 5:  CLR  R17              ; เตรียมค่า LOW (0)
 6:  OUT  PORTB, R17       ; สั่งปิดไฟ LED
 7:  RJMP 3                ; วนลูปกลับบรรทัด 3

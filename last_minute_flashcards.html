📌 1. กฎ DeMorgan & เกต NAND

• (A · B)' = A' + B'
• (A + B)' = A' · B'
• NAND Gate: เอาต์พุตเป็น 0 กรณีเดียวเมื่ออินพุตทุกตัวเป็น 1
• NOR Gate: เอาต์พุตเป็น 1 กรณีเดียวเมื่ออินพุตทุกตัวเป็น 0

📌 2. สูตรวงจรบวก Full Adder

• Sum: Sum = A $\oplus$ B $\oplus$ C_in
• Carry Out: C_out = AB + C_in(A $\oplus$ B)
• Overflow Flag (V): V = C_in(MSB) $\oplus$ C_out(MSB)
(Overflow เกิดเมื่อบวกเลขมีเครื่องหมายแล้วผลลัพธ์ล้นขอบเขต)

📌 3. ฟลิปฟลอป (Characteristic Eqs)

• D FF: Q(t+1) = D (จำค่า D)
• JK FF: Q(t+1) = J·Q' + K'·Q (J=1,K=1 -> Toggle)
• T FF: Q(t+1) = T $\oplus$ Q (T=1 -> Toggle)
• SR FF: S=1,R=1 ห้ามใช้ (Invalid State)

📌 4. 5-Stage Pipeline Hazards

• สเตจ: IF -> ID -> EX -> MEM -> WB
• Structural Hazard: แย่งใช้ฮาร์ดแวร์เดียวกัน
• Data Hazard (RAW): อ่านก่อนเขียนเสร็จ (แก้ด้วย Data Forwarding)
• Control Hazard: กระโดดทิศทาง Branch (แก้ด้วย Branch Prediction/Flush)

📌 5. EC-1 CPU 3-Stage FSM Cycle

• State S0: Fetch Opcode (MAR<-PC, MDR<-RAM, IR<-MDR, PC++)
• State S1: Decode & Fetch Operand (MAR<-IR[3:0], MDR<-RAM)
• State S2: Execute & Writeback (ACC<-ACC+MDR หรือ RAM<-ACC)

📌 6. Hardwired vs Microprogrammed

• Hardwired Control: ต่อสายเกตตรง เร็วมาก แต่แก้ไขฮาร์ดแวร์ยาก เหมาะกับ RISC
• Microprogrammed Control: เก็บไมโครโค้ดใน ROM Control Store ยืดหยุ่น แก้ไขง่าย เหมาะกับ CISC

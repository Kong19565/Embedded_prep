🟢 Chapter 4: AVR I/O Port Programming & Bit Manipulation (Mazidi AVR Textbook Ch. 4)

สรุปเจาะลึกจากตำราเรียนสากล (Enoch Hwang, M. Morris Mano, Mazidi AVR) สำหรับการเตรียมสอบวิชา Embedded System Design

การโปรแกรมพอร์ต I/O

1. DDRx, PORTx, PINx & คำสั่งจัดการบิต SBI / CBI / SBIS / SBIC

คำสั่งบิตรูปแบบ (Syntax)การทำงาน (Operation)
SBISBI PORTB, 5เซตบิตที่ 5 ของ PORTB ให้เป็น 1 (เปิดไฟ LED บน PB5)
CBICBI PORTB, 5เคลียร์บิตที่ 5 ของ PORTB ให้เป็น 0 (ดับไฟ LED บน PB5)
SBISSBIS PINB, 0ข้ามคำสั่งถัดไป 1 บรรทัดถ้าพิน PB0 เป็น 1 (สวิตช์เปิดอยู่)
SBICSBIC PINB, 0ข้ามคำสั่งถัดไป 1 บรรทัดถ้าพิน PB0 เป็น 0 (สวิตช์ถูกกดลงดิน)

1. โครงสร้างภายใน CPU (Register & Stack Organization)

📦 General Register Organization

หน่วยประมวลผลใช้ชุด Register สองฝั่งเชื่อมเข้าสู่ ALU ทางอินพุต A และ B แล้วส่งผลลัพธ์ผ่าน Bus กลับสู่ Register ปลายทาง:

• Bus Selector (SELA / SELB): เลือกตัวแปรอินพุตสำหรับ ALU
• Operation Selector (OPR): กำหนดหน้าที่ ALU (ADD, SUB, AND, SHIFT)
• Destination Selector (SELD): เลือก Register ที่รับผลลัพธ์การคำนวณ

🥞 Stack Organization (LIFO Memory)

โครงสร้างข้อมูลแบบ Last-In, First-Out ควบคุมด้วย Stack Pointer (SP):

• PUSH Operation (เก็บข้อมูลลงสแต็ก):
   SP ← SP - 1   แล้วบันทึกข้อมูล   Memory[SP] ← Data
• POP Operation (ดึงข้อมูลออกจากสแต็ก):
   Data ← Memory[SP]   แล้วคืนค่า   SP ← SP + 1

2. สรุปโหมดการระบุตำแหน่งข้อมูล 7 รูปแบบ (7 Addressing Modes)

Addressing Mode สูตรการคำนวณ Effective Address (EA) ลักษณะการทำงานและตัวอย่าง
1. Implied Mode ไม่ต้องระบุ EA (อยู่ใน Opcode) ระบุตำแหน่งจากคำสั่งโดยตรง เช่น CLC (Clear Carry), NOP
2. Immediate Mode Operand อยู่ในคำสั่งโดยตรง ระบุค่าคงที่โดยตรง เช่น LDI R16, 0xFF (ข้อมูลคือ 0xFF)
3. Register Direct Operand อยู่ใน Register ข้อมูลอยู่ใน Register ที่ระบุ เช่น MOV R1, R2
4. Register Indirect EA = [Register Pointer] Register เก็บที่อยู่ Memory เช่น LD R0, Z (EA = ค่าในคู่ Z)
5. Direct Address EA = Address Field ระบุที่อยู่ Memory ตรงๆ ในคำสั่ง เช่น LDS R16, 0x0100
6. Relative Address EA = PC + Address Field ใช้ที่อยู่สัมพัทธ์กับ PC สำหรับคำสั่งกระโดด เช่น RJMP +5
7. Indexed Mode EA = Index Register + Offset นำค่าใน Index Register บวกกับค่า Offset เพื่อเข้าถึงข้อมูลตาราง array

3. คณิตศาสตร์คอมพิวเตอร์ (Fixed-Point & Floating-Point IEEE 754)

🔢 Fixed-Point Two's Complement & Overflow

การคำนวณเลขมีเครื่องหมาย (Signed Integers) จะใช้ 2's Complement โดยการตรวจจับ Overflow เกิดจาก:

V = Cin ⊕ Cout

• หาก V = 1 : เกิด Overflow ผลลัพธ์ผิดพลาดเนื่องจากล้นหลัก MSB

🌐 IEEE 754 Floating-Point Standard (32-bit Single Precision)

การจัดเก็บเลขทศนิยมประกอบด้วย 3 ส่วน:

Bit 31: Sign Bit (S) | Bits 30..23: Exponent (E, Bias=127) | Bits 22..0: Mantissa (M)

Value = (-1)S × 1.M × 2(E - Bias)

📝 PART C: LINE-BY-LINE EXPLAINED CODE BLUEPRINTS (อธิบายโค้ดตัวอย่างบรรทัดต่อบรรทัด)

2.2 พิมพ์เขียวซอร์สโค้ดพร้อมคำอธิบายการทำงานบรรทัดต่อบรรทัด (Line-by-Line Code Explanations) LINE BY LINE
📂 1. การตั้งค่า Stack Pointer (SPH:SPL = RAMEND) 
.INCLUDE "M328PDEF.INC"
.ORG 0x0000
LDI R16, HIGH(RAMEND)
OUT SPH, R16
LDI R16, LOW(RAMEND)
OUT SPL, R16
💡 อธิบายการทำงานบรรทัดต่อบรรทัด:
• บรรทัด 1 (.INCLUDE "M328PDEF.INC"): ดึงไฟล์นิยามชื่อรีจิสเตอร์และแอดเดรสมาตรฐานของ ATmega328P เข้ามาใช้งาน
• บรรทัด 2 (.ORG 0x0000): กำหนดจุดเริ่มต้นของโปรแกรมให้อยู่ที่แอดเดรสแรก 0x0000 ของ Flash ROM (Reset Vector)
• บรรทัด 3 (LDI R16, HIGH(RAMEND)): ดึงค่า 8 บิตสูงของแอดเดรสสูงสุด SRAM (RAMEND = 0x08FF ➔ HIGH คือ 0x08) ลง R16
• บรรทัด 4 (OUT SPH, R16): ส่งค่า 0x08 ไปยัง Stack Pointer High Register (SPH)
• บรรทัด 5 (LDI R16, LOW(RAMEND)): ดึงค่า 8 บิตต่ำของแอดเดรสสูงสุด SRAM (LOW คือ 0xFF) ลง R16
• บรรทัด 6 (OUT SPL, R16): ส่งค่า 0xFF ไปยัง Stack Pointer Low Register (SPL) เพื่อให้ Stack เริ่มต้นที่ปลายสุด 0x08FF
📂 2. การวนลูปนับเลข 1 ถึง 10 ออกพอร์ต PORTB 
LDI R16, 0xFF
OUT DDRB, R16
LDI R17, 1

COUNT_LOOP:
    OUT PORTB, R17
    CPI R17, 10
    BREQ LOOP_DONE
    INC R17
    RJMP COUNT_LOOP
LOOP_DONE:
💡 อธิบายการทำงานบรรทัดต่อบรรทัด:
• บรรทัด 1 (LDI R16, 0xFF): โหลดค่า 0xFF (111111112) ลง R16 เพื่อเตรียมตั้งค่าทุกพินเป็นเอาต์พุต
• บรรทัด 2 (OUT DDRB, R16): ส่งค่า 0xFF ไปยัง Data Direction Register Port B (DDRB) เพื่อตั้งค่าขา PB0-PB7 เป็น Output
• บรรทัด 3 (LDI R17, 1): กำหนดค่าเริ่มต้นของตัวนับใน R17 ให้เท่ากับ 1
• บรรทัด 4 (COUNT_LOOP:): ป้ายกำกับ (Label) จุดเริ่มต้นของลูปการนับ
• บรรทัด 5 (OUT PORTB, R17): ส่งค่านับปัจจุบันใน R17 ออกไปแสดงผลทางขาพอร์ต PORTB
• บรรทัด 6 (CPI R17, 10): เปรียบเทียบค่าใน R17 กับ 10 (ทดลองลบ R17 - 10 ถ้าเท่ากัน จะเซตธง Zero Flag Z=1)
• บรรทัด 7 (BREQ LOOP_DONE): ถ้า Z=1 (นับครบ 10 เท่ากันแล้ว) ให้กระโดดไปที่ป้าย LOOP_DONE เพื่อจบลูป
• บรรทัด 8 (INC R17): เพิ่มค่านับใน R17 ขึ้นทีละ 1 (R17 = R17 + 1)
• บรรทัด 9 (RJMP COUNT_LOOP): กระโดดกลับไปทำบรรทัดแรกของลูป COUNT_LOOP อีกครั้ง
📂 3. การอ่านปุ่มกด Active Low สวิตช์ PINC0 ควบคุมไฟ LED PORTB5 
SBI DDRB, 5
CBI DDRC, 0
SBI PORTC, 0

READ_SWITCH:
    SBIC PINC, 0
    RJMP TURN_OFF
TURN_ON:
    SBI PORTB, 5
    RJMP READ_SWITCH
TURN_OFF:
    CBI PORTB, 5
    RJMP READ_SWITCH
💡 อธิบายการทำงานบรรทัดต่อบรรทัด:
• บรรทัด 1 (SBI DDRB, 5): Set Bit 5 ของ DDRB ให้เป็น 1 เพื่อตั้งขา PB5 เป็นเอาต์พุตสำหรับต่อไฟ LED
• บรรทัด 2 (CBI DDRC, 0): Clear Bit 0 ของ DDRC ให้เป็น 0 เพื่อตั้งขา PC0 เป็นอินพุตสำหรับต่อปุ่มกด
• บรรทัด 3 (SBI PORTC, 0): Set Bit 0 ของ PORTC ให้เป็น 1 ขณะอยู่โหมด Input เพื่อเปิดใช้งาน Internal Pull-up Resistor
• บรรทัด 5 (SBIC PINC, 0): เช็คพิน PC0 ถ้าปุ่มกดถูกกดลงดิน (เป็น 0) ให้ข้ามคำสั่งบรรทัดถัดไป / ถ้ายังไม่ได้กด (เป็น 1) ทำบรรทัดถัดไป
• บรรทัด 6 (RJMP TURN_OFF): ทำงานเมื่อไม่ได้กดปุ่ม ให้กระโดดไปดับไฟ LED
• บรรทัด 8 (SBI PORTB, 5): ทำงานเมื่อกดปุ่ม (เพราะถูกข้ามมา) ให้ส่งไฟ 5V ออกขา PB5 ติดไฟ LED
• บรรทัด 9 (RJMP READ_SWITCH): กระโดดกลับไปอ่านค่าสวิตช์วนลูปต่อเนื่อง
📂 4. อัลกอริทึมแปลง Hex เป็น BCD 2 หลักด้วยวิธีลบซ้ำด้วย 10

💡 อธิบายการทำงานบรรทัดต่อบรรทัด:
• บรรทัด 1 (LDI R16, 0x45): โหลดค่าคงที่ Hex 0x45 (69 ทศนิยม) เข้า R16 เป็นข้อมูลอินพุตเริ่มต้น
• บรรทัด 2 (CLR R17): ล้างค่า R17 เป็น 0x00 สำหรับใช้นับจำนวนหลักสิบ (Tens digit)
• บรรทัด 4 (CPI R16, 10): เปรียบเทียบค่าที่เหลือใน R16 กับ 10
• บรรทัด 5 (BRLO BCD_DONE): ถ้าน้อยกว่า 10 (เกิด Carry C=1) ให้กระโดดออกจากลูปไป BCD_DONE (ค่าที่เหลือใน R16 คือหลักหน่วย)
• บรรทัด 6 (SUBI R16, 10): ลบค่าคงที่ 10 ออกจาก R16 (R16 = R16 - 10)
• บรรทัด 7 (INC R17): เพิ่มค่านับหลักสิบใน R17 ขึ้นทีละ 1 (R17 = R17 + 1)
• บรรทัด 8 (RJMP BCD_CONVERT): กระโดดกลับไปวนลบด้วย 10 ต่อไป
• บรรทัด 11 (SWAP R17): สลับบิตของ R17 (เช่น จาก 0000 0110 เป็น 06 ➔ 60) เพื่อย้ายหลักสิบไปไว้ 4 บิตสูง (High Nibble)
• บรรทัด 12 (OR R17, R16): รวมหลักสิบใน 4 บิตสูง และหลักหน่วยจาก R16 ใน 4 บิตต่ำ ได้เป็น BCD สมบูรณ์ (0x69)
• บรรทัด 13 (OUT PORTB, R17): ส่งค่า BCD 0x69 ออกแสดงผลทางพอร์ต PORTB
📂 5. โค้ดแล็บจริง: AssemblyBlink1.asm (ไฟกะพริบพร้อมกัน 2 พอร์ต) 
;====================================================================
; Title: AssemblyBlink1.asm
; Created: 11/22/2013
; Author: khatathapswatdipisal
; Description: Blink all LEDs on PORTB and PORTD simultaneously
;====================================================================

.nolist
.include "m328pdef.inc"
.list

; Start at main after reset
rjmp main

main:
    ldi r16, 0xFF       ; Load 0xFF into R16 (all bits set to 1)
    out DDRB, r16       ; Configure Port B pins as Outputs
    out DDRD, r16       ; Configure Port D pins as Outputs
    ldi r16, 0x00       ; Clear R16 to 0x00

loop:
    com r16             ; Complement R16 (toggle bits between 0x00 and 0xFF)
    out PORTB, r16      ; Write R16 to Port B
    out PORTD, r16      ; Write R16 to Port D
    call MY_DELAY       ; Delay for simulation timing
    rjmp loop           ; Loop indefinitely

; Delay Subroutine
MY_DELAY:
    ldi r20, 8
L1:
    ldi r21, 200
L2:
    ldi r22, 250
L3:
    dec r22             ; Decrement R22
    brne L3             ; Loop if R22 != 0
    dec r21             ; Decrement R21
    brne L2             ; Loop if R21 != 0
    dec r20             ; Decrement R20
    brne L1             ; Loop if R20 != 0
    ret                 ; Return from subroutine
💡 อธิบายการทำงานบรรทัดต่อบรรทัด:
• ldi r16, 0xFF & out DDRB/DDRD, r16: โหลด 0xFF ตั้งค่าขา PORTB และ PORTD ทั้งหมดเป็น Output
• com r16: กลับบิตทุกบิตใน R16 (สลับระหว่าง 0x00 ➔ 0xFF ➔ 0x00) ทำให้ไฟกะพริบติดดับสลับกันตามคาบเวลา
• out PORTB/PORTD, r16: ส่งค่า R16 ออกควบคุมไฟ LED บนทั้งสองพอร์ตพร้อมกัน
• call MY_DELAY: เรียกฟังก์ชันย่อยสร้างความหน่วงเวลาโดยใช้ลูปซ้อนกัน 3 ชั้น (R20, R21, R22) เพื่อให้ตากมองทันการกะพริบ
📂 6. โค้ดแล็บจริง: AssemblyBlink1_modified.asm (ไฟกะพริบสลับพอร์ต PORTB ติดเมื่อ PORTD ดับ) 
;====================================================================
; Title: AssemblyBlink1_modified.asm
; Created: 11/22/2013 (Modified: 2026-07-19)
; Author: khatathapswatdipisal
; Description: Alternate blinking: Port B ON when Port D is OFF
;====================================================================

.nolist
.include "m328pdef.inc"
.list

; Start at main after reset
rjmp main

main:
    ldi r16, 0xFF       ; Load 0xFF into R16 (all bits set to 1)
    out DDRB, r16       ; Configure Port B pins as Outputs
    out DDRD, r16       ; Configure Port D pins as Outputs
    ldi r16, 0x00       ; Clear R16 to 0x00

loop:
    com r16             ; Complement R16 (toggle R16 between 0x00 and 0xFF)
    out PORTB, r16      ; Write R16 directly to Port B (PB0-PB7)
    
    mov r17, r16        ; Copy R16 to R17
    com r17             ; Complement R17 (so R17 is always the opposite of R16)
    out PORTD, r17      ; Write R17 to Port D (PD0-PD7)
    
    call MY_DELAY       ; Delay for simulation timing
    rjmp loop           ; Loop indefinitely

; Delay Subroutine
MY_DELAY:
    ldi r20, 8
L1:
    ldi r21, 200
L2:
    ldi r22, 250
L3:
    dec r22             ; Decrement R22
    brne L3             ; Loop if R22 != 0
    dec r21             ; Decrement R21
    brne L2             ; Loop if R21 != 0
    dec r20             ; Decrement R20
    brne L1             ; Loop if R20 != 0
    ret                 ; Return from subroutine
💡 อธิบายการทำงานบรรทัดต่อบรรทัด:
• com r16 & out PORTB, r16: กลับบิต R16 และส่งออก PORTB (เช่น PB=0xFF ไฟติด)
• mov r17, r16 & com r17 & out PORTD, r17: ก๊อบปี้ R16 ลง R17 แล้วกลับบิต R17 เพื่อให้ R17 มีค่าตรงข้ามกับ R16 เสมอ (เช่น PD=0x00 ไฟดับ) ทำให้ทั้งสองพอร์ตติดดับสลับกัน

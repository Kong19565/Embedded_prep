📌 1. โครงสร้างฮาร์ดแวร์ รีจิสเตอร์ และพอร์ต I/O ของ ATmega328P

1.1 รีจิสเตอร์สถานะ Status Register (SREG)

Bit 7Bit 6Bit 5Bit 4Bit 3Bit 2Bit 1Bit 0
I (Interrupt) T (Bit Copy) H (Half Carry) S (Sign Bit $S=N ⊕ V$) V (Overflow) N (Negative) Z (Zero) C (Carry)

• Z (Zero): เป็น 1 เมื่อผลลัพธ์คำนวณเป็น 0
• C (Carry): เป็น 1 เมื่อมีตัวทดออกจาก MSB (บิต 7)
• V (Overflow): เป็น 1 เมื่อเกิดการล้นของเลขมีเครื่องหมาย 2's Complement

1.2 รีจิสเตอร์ควบคุมพอร์ต I/O (PORTB, PORTC, PORTD)

💻 3. แม่แบบโค้ดแอสเซมบลีที่ออกสอบบ่อย (5 Essential Code Templates)

Template 1: การตั้งค่าพอร์ต I/O และควบคุมไฟ LED ตามสวิตช์

.INCLUDE "M328PDEF.INC"
.ORG 0x0000

LDI R16, HIGH(RAMEND)   ; ตั้งค่า Stack Pointer
OUT SPH, R16
LDI R16, LOW(RAMEND)
OUT SPL, R16

LDI R16, 0xFF
OUT DDRB, R16           ; ตั้ง PORTB เป็น Output (LEDs)
LDI R16, 0x00
OUT DDRC, R16           ; ตั้ง PORTC เป็น Input (Switches)
LDI R16, 0xFF
OUT PORTC, R16          ; เปิด Pull-up Resistors บน PORTC

MAIN_LOOP:
    IN R16, PINC        ; อ่านค่าจากสวิตช์ PINC
    COM R16             ; กลับบิต (Active Low Switch)
    OUT PORTB, R16      ; ส่งออกไฟ LED PORTB
    RJMP MAIN_LOOP

Template 2: การแปลงเลขฐานสิบหก 0-99 เป็น BCD สองหลักด้วยวิธีลบซ้ำด้วย 10

; Input: R16 (Hex value 0x00 - 0x63), Output: R17 (BCD Packed 2 digits)
HEX_TO_BCD:
    CLR R17             ; R17 เก็บตัวนับหลักสิบ (Tens digit)
SUB_LOOP:
    CPI R16, 10         ; เปรียบเทียบกับ 10
    BRLO SUB_DONE       ; ถ้า R16 < 10 ให้จบการลบ
    SUBI R16, 10        ; R16 = R16 - 10
    INC R17             ; หลักสิบเพิ่มทีละ 1
    RJMP SUB_LOOP
SUB_DONE:
    SWAP R17            ; ย้ายหลักสิบขึ้น 4 บิตสูง (MSB Nibble)
    OR R17, R16         ; รวมหลักสิบและหลักหน่วยเข้าเป็น BCD
    OUT PORTB, R17      ; ส่งออกแสดงผล PORTB

Template 3: วนลูปคำนวณผลรวมสะสม S = 1 + 2 + ... + n

; คำนวณ S = N + (N-1) + ... + 1 (เช่น N=5 -> S=15)
LDI R16, 5              ; N = 5
CLR R17                 ; R17 เก็บผลรวมสะสม Sum = 0
SUM_LOOP:
    ADD R17, R16        ; Sum = Sum + N
    DEC R16             ; N = N - 1
    BRNE SUM_LOOP       ; วนลูปจนกว่า N = 0 (Z=1)
OUT PORTB, R17          ; ส่งผลรวมออก PORTB (15 = 0x0F)
